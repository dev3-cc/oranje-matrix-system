# FICHA DETALLADA — BUSINESS DEVELOPER

---

| Campo                          | Contenido                                                                                                                                                                                                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ID Rol**                     | ROL-V-01                                                                                                                                                                                                                                                    |
| **Nombre del Rol**             | 🤝 Business Developer (BD)                                                                                                                                                                                                                                  |
| **Descripción**                | Ejecutor comercial en campo. Identifica prospectos, hace visitas en frío, elabora propuestas, da seguimiento y gestiona rechazos. Subordinado del BDC.                                                                                                      |
| **Objetivo en el Sistema**     | Llevar el máximo de hoteles a status Naranja en su territorio, ejecutando el ciclo del Semáforo Onboarding.                                                                                                                                                 |
| **Módulos que Usa**            | Dashboard · Pipeline · Mi Territorio · Propuestas · Contratos · Clientes Activos · Notificaciones                                                                                                                                                      |
| **Permisos (CRUD)**            | Crear · Ver · Editar (sin eliminar) · Avanzar status · Marcar Rojo / Café                                                                                                                                                                                   |
| **Acciones Principales**       | Identificar prospecto · Crear perfil · Visita en frío · Elaborar Propuesta · Enviar Propuesta · Crear T&C · Negociar (Rosa) · Gestionar Rojo · Marcar Café                                                                                                  |
| **Nivel de Acceso**            | 🟡 Medio (operativo)                                                                                                                                                                                                                                        |
| **Dispositivo**                | Mobile (prioritario) / Tablet / Desktop                                                                                                                                                                                                                     |
| **Frecuencia de Uso**          | Alta — diaria                                                                                                                                                                                                                                               |
| **Dolor / Necesidad Actual**   | Visitas en frío sin un sistema móvil ágil; pérdida de seguimiento entre prospectos; propuestas elaboradas en plantillas Word; visibilidad limitada de su pipeline real; difícil priorizar a quién contactar primero.                                        |
| **Notas UX / Recomendaciones** | App mobile prioritaria con creación rápida desde mapa, plantilla de propuesta editable en mobile, recordatorios automáticos de seguimiento, dashboard con próximos contactos priorizados, geolocalización al identificar prospecto, sincronización offline. |
