## TIPOS DE REQUERIMIENTO

| Prefijo | Tipo | Descripción |
|---|---|---|
| **RF** | Requerimiento Funcional | Define QUÉ hace el sistema — comportamientos, acciones, flujos |
| **RNF** | Requerimiento No Funcional | Define CÓMO lo hace — rendimiento, seguridad, usabilidad |
| **RR** | Requerimiento de Negocio | Define POR QUÉ existe — reglas, políticas, restricciones |
| **RI** | Requerimiento de Integración | Define CON QUÉ conecta — notificaciones, catálogos, módulos externos |
